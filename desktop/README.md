# Windows-сборка Motivelium

Windows **0.2.0-beta.1**: WinForms/WebView2, .NET Framework 4.8, x64; собственный Node 24.12.0 и 20 production-пакетов, включая MCP SDK и Zod. Выпуск beta.1 включает MCP и RU/EN. Прежняя alpha.3 сохраняется в истории выпусков. Основная поставка — NSIS-установщик. Свой код — MIT; чужие лицензии сохраняются в `licenses/`.

## Сборка из архива исходников

Нужны Windows x64, Node 24.12.0 с npm, Python 3.14 с Pillow и компилятор .NET Framework `csc.exe`. Пользователь установленной программы эти сборочные инструменты не устанавливает.

1. Распакуйте весь архив исходников в отдельную папку, откройте терминал в ней.
2. Выполните `node tools/setup.mjs`: собственный `npm ci` и сборка интерфейса. Настройки автора не нужны.
3. Выполните `py -3.14 tools/license-report.py --verify`. Проверяются lockfile, полные уведомления, 424 сохранённых оригинала шейдеров и SHA модели. Проверка не требует прежней папки `lab/` и не обращается к сети.
4. Выполните `node tools/sync-version.mjs --check`, затем `py -3.14 desktop/build-installer.py --out D:/Builds/Motivelium-candidate`. Папка результата должна быть новой. Компилятор NSIS 3.13 загружается с официального источника и проверяется по закреплённому SHA-256 до распаковки. Node и SDK WebView2 также проверяются по закреплённым хешам.

Подготовить только NSIS можно командой `py -3.14 tools/prepare-windows-build.py`. Кэш — `.build-cache/windows`, устанавливать NSIS в систему не требуется. При собственном компиляторе передайте `--compiler ПУТЬ --compiler-archive ПУТЬ_К_ПРОВЕРЕННОМУ_ZIP`.

Скрипт `tools/license-report.py` без `--verify` регенерирует сведения из авторского кэша upstream и предназначен для сопровождения зависимостей; для обычной сборки из поставленных исходников он не нужен. Обновление lockfile или стороннего кода требует нового просмотра лицензий и уведомлений.

`version.json` задаёт текущую версию. `node tools/sync-version.mjs` синхронизирует метаданные пакетов, EXE и уведомлений; поддерживаются alpha, beta, rc и стабильный выпуск. NSIS получает обозначение и числовую PE-версию от сборщика. Исторические ссылки в документации не переписываются. Для одного ядра версии числовые ревизии Windows упорядочены: alpha.N → N, beta.N → 10000+N, rc.N → 20000+N, стабильный выпуск → 65535; N не больше9999.

`--payload ПАПКА` позволяет перепаковать уже проверенный payload той же версии. Этот режим не компилирует изменённые исходники EXE; при изменении программы нужен новый payload. Несовпадение версии `app/version.json` отклоняется. Итоговый `installer-manifest.json` фиксирует SHA каждого файла, Setup и настоящего деинсталлятора. Сборка не публикует файлы и не делает push.

## Установка и хранение

Setup и Uninstall запрашивают UAC; редактор имеет `asInvoker` и запускается пользователем из меню «Пуск». Каталог и регистрация относятся к текущей учётной записи Windows; при вводе другой учётной записи выбирается её профиль. Автоматического запуска редактора из повышенного Setup нет.

Данные установленной версии — `%LOCALAPPDATA%/Motivelium`, переносимой — `app/.local`. Абсолютный `MOTIVELIUM_DATA_DIR` выбирает отдельный стенд. Обновление/удаление не удаляет отдельную папку данных; удаляются только известные файлы программы и пустые каталоги. Неизвестные пользовательские файлы сохраняются. При открытой установленной студии обновление и удаление отклоняются; процессы пользователя не завершаются. Перенос старых проектов — ZIP, автоматической миграции нет.

## Проверки и границы

Обычный запуск не открывает CDP. `--qa-session` и `--self-test` — явные тестовые входы собственного WebView2. NSIS `/QA` изолирует ярлыки/регистрацию и по умолчанию использует Motivelium-QA; сам по себе он не доказывает настоящую регистрацию Windows.

20.10.2026 пользователь подтвердил реальный UAC, обновление до alpha.3 и запуск из «Пуска». У готового экземпляра проверены обычные права редактора/сервера, прежний граф и два медиа; данные сохранились. Ранний отказ записи инструментального запуска при пользовательском запуске не воспроизвёлся, точная причина различия не установлена. 21.10.2026 на новой Windows 11 LTSC 26100 в Hyper-V настоящий Setup `/S` без `/QA` прошёл регистрацию HKCU, ярлык и 2956 SHA. Обычные editor/backend/UI-worker прошли свои материалы, перезапуск, MP4 12 с/720p/H.264/AAC, ZIP в пустое хранилище, правку и Undo. Видео/звук/полный граф/4 ресурса проверены независимо. Внешние пользовательские пробы остаются отдельным этапом.

29.10.2026 та же сохранённая VM3 использована для текущего alpha.4-кандидата: обычный Setup без `/QA`, 4151 совпадающий файл, свои текст/PNG/MP3, перезапуск, MP4 со звуком, ZIP в другое хранилище и Undo. Удаление/повторная установка сохранили379 файлов данных. Дополнительная проверка EN-настроек остановилась на неверном селекторе теста; её успешное прохождение на этой VM не заявляется. Новые VM и диски не создавались. Точная готовность следующего выпуска — [BETA_READINESS.md](../docs/BETA_READINESS.md).

WebView2 Evergreen/.NET, FFmpeg/FFprobe/Chrome/Python не упакованы. EXE и Setup не подписаны сертификатом издателя. GSAP и старый vendor Three.js в runtime не входят. История прежнего выпуска — `docs/RELEASE_0_1.md`.
