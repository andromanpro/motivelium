# Motivelium 0.1.0-alpha.3

Откройте Motivelium.exe либо ярлык Motivelium в меню «Пуск».

Установка, обновление и удаление требуют подтверждения UAC. Редактор открывайте из меню «Пуск» с обычными правами. Отмена запроса Windows отменяет запуск операции; проекты и материалы сохраняются.

Нужны Windows10/11 x64, .NET Framework4.8 и Microsoft WebView2 Evergreen Runtime. Node и библиотеки включены. Для своих медиа нужен FFprobe; для MP4 — FFmpeg с libx264/AAC, FFprobe и Chrome. Настройка и диагностика — в студии. Python3.14 нужен только для необязательного ИИ. Ключи автора в комплекте отсутствуют.

Начните с одного из трёх шаблонов, замените текст, картинку и музыку. Создаётся собственный проект; исходный шаблон остаётся нетронутым. Сохраняйте ZIP для переноса и резервного копирования.

Установленная версия: данные `%LOCALAPPDATA%/Motivelium`, отдельно от программы. Обновление и удаление программы их сохраняют. Переносимая копия: app/.local. Старую копию переносите через ZIP; автоматической миграции нет.

Свой код — MIT, полный текст LICENSE. Условия стороннего кода и модели — THIRD_PARTY.md и licenses/. README.md содержит быстрый старт, app/docs/INSTALLATION.md — подробности и официальные ссылки на зависимости.

Сборка предварительная и без подписи издателя. Свежая Windows и внешние пробы ещё нужны. Публичная публикация не выполнялась.
