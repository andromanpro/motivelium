# Изменения Motivelium

## 0.2.0-beta.1 — 30.10.2026

- Первый beta-выпуск AI-first: внешний MCP, настоящие кадры примерки, ручная доводка, сравнение и отмена.
- RU/EN интерфейса, справки, четырёх примеров и трёх шаблонов; светлая/тёмная/системная тема.
- Переработанные разряд, типографика, предметное 3D и бумажный коллаж.
- Звуковой монтаж, хранение/перенос, диагностика компонентов и иллюстрированный старт.
- Общая проверка alpha/beta/rc/stable и метаданные Windows изversion.json.
- Подробности и ограничения — docs/RELEASE_BETA1.md.

## Кандидат 0.1.0-alpha.4 — 28.10.2026

- Внешний MCP, компактная выборка, раскадровка и монтаж, ограниченный бюджет, общая примерка и история.
- Звуковой монтаж и сетка долей; общий звук просмотра и MP4.
- Папка данных в настройках, предварительный просмотр другого хранилища и перенос выбранного проекта копией без изменения источника.
- Просмотр встроенных примеров без создания проекта; собственная копия отдельным действием.
- Диагностика компонентов, пути Chrome/FFmpeg/FFprobe и перезапуск; внешний MCP отделён от встроенного GLM.
- Иллюстрированная справка и короткий первый маршрут. Публичная alpha.3 не заменена.

## История первого этапа MCP после alpha.3

- Локальный MCP stdio на официальном SDK: 21 инструмент, подключение к работающей студии без её перезапуска.
- Каталог эффектов/шейдеров/шаблонов/композиций со схемами, создание проекта, импорт медиа и моделей.
- Неизменяемая примерка пакета операций, настоящие PNG и короткий MP4 общего рендерера; до трёх доработок.
- Применение одной идемпотентной транзакцией, общая ручная доводка и Undo/Redo, защита от конфликта ревизий.
- Экспорт MP4 со звуком, статус/отмена и ZIP проекта. Внешний агент выбирает модель; MCP не требует GLM-ключа.
- Новое демо «Ещё одна правка» создано через MCP. Опубликованные файлы alpha.3 не заменялись.

## Проверки alpha.3 — 21.10.2026

- Полный маршрут Setup → свой ролик → перезапуск → MP4 со звуком → ZIP и продолжение правок прошёл на новой Windows 11 LTSC 26100.
- Доступны отдельный набор примеров, инструкции и контрольные суммы. Подробности и границы — docs/RELEASE_0_1.md.

## 0.1.0-alpha.3 — запрос прав Windows, 20.10.2026

- Установка, обновление и удаление программы запрашивают подтверждение UAC. При отмене Windows не запускает операцию.
- Редактор сохраняет обычный уровень прав. После установки он открывается пользователем из меню «Пуск»; запуск из повышенного установщика убран.
- Данные и история проектов по-прежнему хранятся отдельно; очистка файлов программы не удаляет проекты и неизвестные пользовательские файлы.
- Штатный запрос прав Windows выбран для установки; редактор продолжает работать без повышения.


## 0.1.0-alpha.2 — проверка обычной установки, 20.10.2026

- Доступ к меню «Пуск» и регистрации HKCU проверяется до распаковки и замены файлов программы. Отказ прав больше не оставляет новую частичную установку.
- Собственный деинсталлятор может убрать файлы незавершённой установки с корректным маркером, даже если регистрация Windows не успела создаться. Другая зарегистрированная папка защищена от удаления.
- Добавлена отдельная программа проверки обычной установки: запуск через настоящий ярлык, переход alpha.1 → alpha.2, удаление и повторная установка с проверкой сохранности проектов. Она не использует /QA и запускается пользователем в обычном контексте Windows.
- На этом этапе появился отдельный проверочный маршрут установки.


## 0.1.0-alpha.1 — кандидат, 20.10.2026

- Студия сцен и слоёв, прямое редактирование на холсте, ключи трансформаций, отмена/повтор.
- Галереи эффектов, переходов, масок, шейдеров и готовых редактируемых композиций с примеркой.
- Детали статических 3D-моделей, камера, свет и атмосфера.
- Необязательные ИИ-правки с кадрами до/после и ограниченной самопроверкой.
- Три стартовых шаблона: отдельный проект при создании, свои текст, картинки и музыка.
- MP4 H.264/AAC через внешние Chrome/FFmpeg/FFprobe; перенос проекта и ресурсов через ZIP.
- Windows EXE со своими Node и npm-пакетами, нативным сохранением и собственным окном WebView2.
- Исправлены сброс настроек при смене порта и сообщение повреждённого ZIP.
- R6: MIT для своего кода, реестр сторонних компонентов и полные уведомления; установщик для текущего пользователя с ярлыками и удалением. Данные отделены от заменяемых файлов программы.

На этапе alpha.1 установщик/EXE не подписаны; проверка отдельной Windows ещё не выполнялась. Инструменты MP4, .NET и Evergreen Runtime не упакованы и не устанавливаются скрыто.
