# Примеры Motivelium

Внутри программы находятся три стартовых шаблона (Спектр, Маршрут, Сигнал) и три компактных редактируемых демо (Обзор возможностей, Разряд, Материя). Создание из них всегда даёт собственную копию. Их ресурсы доступны сразу после установки, сеть не нужна.

Большие примеры поставляются **отдельным архивом** `Motivelium-Examples-0.1.0-alpha.3.zip`. Он не устанавливается вместе с EXE и не копируется автоматически в папку проектов.

## Механика — три сборки

Первый дополнительный пример: CarConcept → Perseverance → Ingenuity → общая сборка, 25,6 секунды, 1920×1080, 30 fps. Камеры, отдельные детали, ключи, переходы, свет и музыка остаются редактируемыми.

В наборе:

- `Механика-три-сборки.mp4` — готовое видео со звуком для обычного просмотра;
- `Механика-три-сборки.motivelium.zip` — проект с тремя GLB и музыкой;
- `Авторы-моделей-и-музыки.md`, `Источники-моделей.json`, `Лицензии/` — авторство, условия использования и описание подготовки моделей;
- `manifest.json` — размеры и контрольные суммы файлов.

Распакуйте внешний набор. Для просмотра откройте MP4 любым подходящим проигрывателем. Для редактирования нажмите «Импортировать» на главной студии и выберите **внутренний файл `.motivelium.zip`**. Не подавайте весь архив набора примеров как ZIP проекта. После проверки задайте название и импортируйте копию. Модели и музыка находятся в проекте; подключения к исходной рабочей папке автора нет.

История прежних отмен не переносится. Новая копия начинает собственную историю. Производные модели и их условия не становятся MIT-кодом приложения: сохраняйте приложенные уведомления при дальнейшем распространении материалов. Разборка иллюстративная, не инструкция по ремонту; использование материалов NASA не означает одобрения продукта NASA.

Готовые авторские проморолики по другим проектам не входят в этот набор автоматически. Их можно подготовить отдельными примерами после отбора ресурсов и проверки условий.
