# Внешняя проба Motivelium beta.1

Для отдельной Windows 10/11 x64 и первой группы из 5–10 технических пользователей. Нужен комплект0.2.0-beta.1 сборки `20261030-beta1`, а не публичная alpha.3 без MCP. Приглашения автоматически не отправляются; прохождение пользователями не засчитано заранее. Начните с [маршрута со скриншотами](FIRST_VIDEO.md). Предложение следующего номера и оставшиеся проверки — [BETA_READINESS.md](BETA_READINESS.md).

## Подготовка

Нужны .NET Framework 4.8, WebView2 Evergreen, а для своих файлов и MP4 — FFprobe, FFmpeg с libx264/AAC и Chrome. Порядок и официальные ссылки в `INSTALLATION.md`. Устанавливайте программы из выбранных вами источников; дополнительные программы в Setup Motivelium не включены.

Перед обновлением существующей версии сохраните ZIP нужных проектов или резервную копию папки данных при закрытой студии. Проверяйте на собственном тестовом проекте.

## MCP-проверка

В «Настройки → ИИ» скопируйте конфигурацию в своего MCP-клиента. Скопируйте пробное поручение, проверьте результат до применения, примените подходящий вариант и отмените. Отметьте время и место затруднения. Если своего MCP-клиента нет, отдельно пройдите ручной маршрут; это не подтверждает подключение ИИ.

## Маршрут

1. Установите Motivelium через Setup с UAC. Откройте из «Пуска» обычным способом. Запишите версию из «Справка → О программе».
2. Откройте «Шаблоны», посмотрите живое превью и создайте свою копию «Спектра».
3. Замените заголовок, изображение и музыку своими файлами. Измените громкость и смещение. Сделайте отмену и повтор; убедитесь, что исходный шаблон не изменился.
4. Закройте окно, снова откройте из «Пуска». Проект и ваши материалы должны сохраниться.
5. Через «Экспорт → Видео MP4» получите ролик. Откройте готовое видео: проверьте начало/конец, звук и отсутствие заметных скачков.
6. Через «Файл → Скачать проект» получите ZIP. На главной импортируйте его под новым названием. Сравните кадр, измените текст и отмените правку. Исходный проект должен остаться прежним.
7. По желанию импортируйте дополнительный пример «Механика — три сборки» и проверьте перемотку к каждой модели, разборку/сборку и звук.

Дополнительно: в «Примеры» посмотреть все три демо без создания проектов; создать свою копию; в «Настройки → Хранилище» проверить путь и перенести проект из другой папки. Если папки нет — отметить «не проверял», не создавать фиктивный успешный результат.

## Результат

Пришлите сведения без ключей и личных файлов:

```text
Версия Motivelium:
Windows и видеокарта:
Установка / запуск из Пуска:
MCP-клиент / подключение / примерка / применение / отмена:
Создание / свои материалы / отмена:
Перезапуск и сохранность:
MP4 — картинка, звук, длительность:
ZIP и редактирование копии:
Где понадобилась помощь или инструкция оказалась непонятной:
Ошибка — точный текст, шаг и при необходимости снимок:
```

Проба считается успешной, когда новый пользователь завершает маршрут без помощи автора и без потери данных. Отдельно отмечайте ошибки зависимости или инструкции: их нельзя считать успешным MP4-экспортом.
