# Видеофрагменты — рабочая сборка после beta.1

## В студии

1. Откройте **Ресурсы → Добавить файл**, выберите MP4, затем **Добавить в сцену**. Импорт и вставка — отдельные отменяемые действия. Исходник сохраняется целиком.
2. Выберите видеослой. В **Свойствах → Видео: обрезка и оформление** задайте начало и конец исходника, скорость, размещение, громкость и отключение звука.
3. Перематывайте примерку, сравнивайте **До / После**. Пока не нажато **Применить изменения**, документ остаётся прежним. Закрытие отменяет примерку. При изменении проекта другим окном применение блокируется.
4. Применение — одна транзакция. **Отменить / Повторить** возвращают параметры и звук. Положение, размеры, ключи и обычные эффекты редактируются как у других слоёв.

Видеослой начинается с начала своей сцены. Для другого момента начала используйте отдельную сцену. Конец исходного диапазона исключён: после него можно оставить последний допустимый кадр или скрыть видео. Звук после конца диапазона прекращается в обоих режимах.

Звук видео — видимая дорожка общего микса. Её время связано с видеослоем; громкость, тип и отключение доступны отдельно. Удаление видеослоя удаляет связанную дорожку той же операцией; отмена восстанавливает обе. Изменение скорости меняет и высоту звука; сохранение высоты ещё не реализовано.

## MCP

`import_media` принимает MP4 из разрешённой `--asset-root`. `capabilities(section:"nodes")` описывает видеослой; `list_nodes(kind:"video")` возвращает компактные параметры. Создание, обрезка и скорость выполняются обычным `propose_changes`, затем `render_preview`, `apply_draft`, `undo/redo`.

Специфические поля узла:

```json
{"kind":"video","assetId":"ID из import_media","fit":"contain","sourceIn":155,"sourceOut":165,"speed":1,"endBehavior":"hold"}
```

Дополнительно нужны обычные поля слоя: `id/name/sequenceId/parentId/geometry/transform/visible/locked`. Чтобы включить звук, добавьте `addAudioTrack` с тем же `assetId` и `videoNodeId`, равным ID видеослоя; обычные `gain/offsetSeconds/mute/kind/id` обязательны. Время звука рассчитывается по узлу, значение offset для связанной дорожки не задаёт независимый сдвиг.

## Совпадение предпросмотра и экспорта

Один декодер FFmpeg готовит PNG по SHA исходника и номеру кадра. Студия, MCP и MP4 используют этот путь. Подготовка асинхронная; завершение устаревшей перемотки не заменяет новый остановленный кадр. При проигрывании очередь объединяет запросы и подгружает два следующих блока до запуска звуковых часов. Под большой нагрузкой предпросмотр может пропускать кадры; экспорт считает каждый кадр.

Размер промежуточного изображения учитывает размер проекта и максимальный зум камеры и не превышает исходник. Блоки адаптируются к разрешению; одновременно работают до двух декодеров, память кэша ограничена. Временные PNG удаляются после загрузки блока. Кэш не входит в ZIP.

Экспорт и MCP-примерка читают свои снимки ресурсов, не меняющийся живой документ. ZIP содержит исходный MP4, параметры монтажа и требование читателя `video-clips-v1`. При импорте повторно проверяются SHA и фактические метаданные MP4. Прежний читатель должен предложить обновление.

## Границы первой реализации

- MP4: H264, постоянная частота 1–120 fps, до 4096 пикселей по стороне / 8,8 Мп, до часа; файл до 64 МиБ. Поддерживаются дробные частоты вроде 30000/1001.
- Постоянство проверяется по временным меткам всех видеопакетов, а не только по заявленному среднему fps. VFR, повёрнутые источники и другие кодеки нужно предварительно преобразовать.
- Звук: одна AAC-дорожка, моно или стерео; также допустим источник без звука. Встроенные субтитры, главы и служебные дорожки исходника не становятся отдельными слоями.
- Нужны FFmpeg и FFprobe. Для MP4-экспорта по-прежнему нужен Chrome. Они не устанавливаются автоматически.
- Готовый MP4 можно оформить точками внимания, курсором, щелчками и плавным приближением: [инструкция](SCREEN_GUIDE.md). Встроенная запись экрана и автоматическое извлечение действий из пикселей пока отсутствуют.
- Обратное воспроизведение и повтор исходного диапазона отсутствуют. Эффекты с накоплением прошлых видеокадров пока недоступны; пространственные эффекты и переходы сцен работают.
- Ограничения общего микса, экспорта и ZIP остаются прежними. Привязанные к конкретному компьютеру пути в проект не записываются.
