# Установка Motivelium 0.1.0-alpha.4

## Установщик Windows — основной путь R6

Motivelium-0.1.0-alpha.4-Setup-x64.exe устанавливает программу для текущего пользователя с подтверждением прав администратора (UAC). Каталог по умолчанию: `%LOCALAPPDATA%/Programs/Motivelium`. Ярлыки — меню «Пуск» и, по выбору, рабочий стол. Удаление — настройки приложений Windows или Uninstall.exe.

Откройте установщик обычным двойным щелчком и подтвердите запрос Windows. Обновление и удаление используют такой же запрос. Если отменить UAC, Windows не запустит операцию. Редактор открывается отдельно из меню «Пуск» с обычными правами; из повышенного установщика он автоматически не запускается.

Установка остаётся привязана к учётной записи Windows. Для существующих проектов используйте ту же учётную запись; запуск под другой учётной записью выбирает другой пользовательский профиль. Общая установка для всех пользователей не заявлена.

Данные установленной версии лежат отдельно в `%LOCALAPPDATA%/Motivelium`: projects, runtime.json, задания, журналы и webview2. Обновление/удаление их сохраняет. При открытой установленной студии сначала закройте её. Если установленная копия не найдена или Windows отказала регистрации/созданию ярлыков, установщик сообщает ошибку. Защитные настройки Windows/права не меняет.

Требования: Windows10/11 x64, .NET Framework4.8 ([Microsoft](https://dotnet.microsoft.com/download/dotnet-framework/net48)), [WebView2 Evergreen Runtime](https://developer.microsoft.com/microsoft-edge/webview2/#download-section). Node24.12.0 и закреплённые production-библиотеки включены. Chrome, FFmpeg/FFprobe и Python не включены и автоматически не скачиваются. FFprobe нужен для своих медиа; Chrome/FFmpeg/FFprobe — для MP4; Python3.14 — только для GLM.

Установщик/EXE без подписи издателя. Перенос прежних проектов — через ZIP или отдельной копией в настройках хранилища после предварительного просмотра; автоматической миграции .local нет. Перед обновлением рекомендуется ZIP/резервная копия данных при закрытой студии. Абсолютный MOTIVELIUM_DATA_DIR задаёт отдельный стенд.

**Далее — прежняя инструкция для исходников/portable.** Упоминания .local/runtime.json в ней для установленной версии означают runtime.json в папке данных выше. Относительные пути инструментов разрешаются от app/ программы; для постоянных внешних инструментов предпочтительны абсолютные пути. Никакие ключи и собственные инструменты из среды автора не подхватываются автоматически.

# Установка Motivelium на Windows

Ниже описан запуск из исходников или переносимого комплекта. Для установленной программы используйте начало этой инструкции. Свой код — MIT; сторонние условия перечислены в THIRD_PARTY.md и licenses/. Публично доступна alpha.3; этот документ описывает локальный кандидат alpha.4, его публикация согласуется отдельно.

**Переносимая EXE-сборка:** распакуйте всю папку и откройте Motivelium.exe. Node и пакеты уже внутри, SETUP/START не нужны. Используются .NET Framework4.8 и установленный WebView2 Runtime; подробности в desktop/Прочти-меня.md или одноимённом файле рядом с EXE. Ниже — установка из исходников и настройка внешних инструментов.

## Быстрый маршрут

[Первый ролик со скриншотами](FIRST_VIDEO.md). В самой студии: «Справка». Для внешнего ИИ откройте «Настройки → ИИ», скопируйте MCP-конфигурацию и пробное поручение в свой клиент. Этот путь не требует профиля GLM и Python; модель использует ваш клиент.

## Первый запуск

1. Распакуйте комплект в отдельную папку с правом записи. Пробелы и кириллица допустимы. Не запускайте из самого ZIP или из защищённой папки Program Files.
2. Установите **Node.js 24.12 или более новую версию ветки 24.x вместе с npm**. Проверенный runtime — 24.12.0. Другие основные ветки пока не заявлены.
3. Запустите **SETUP.cmd**. Он устанавливает зависимости из `studio/package-lock.json` командой `npm ci`, собирает интерфейс и проверяет инструменты. Для загрузки пакетов npm нужен интернет. Глобальные модули не используются.
4. Запустите **START.cmd**. Адрес студии — `http://127.0.0.1:8676/studio/`. Сервер доступен только с этого компьютера.
5. Создайте проект из шаблона либо пустой проект. Правки сохраняются в `.local/projects` рядом с программой. Перед обновлением сохраните эту папку или выгрузите проекты в ZIP.

Повторный старт этой же копии использует уже работающий сервер. Если порт занят другой копией, она не останавливается. Для новой копии используйте `node launch.mjs --port 8679`. После закрытия окна браузера локальный сервер продолжает работать; для его штатного завершения используйте терминал с `node server.mjs` и Ctrl+C либо завершите именно свой PID из `.local/server-НОМЕР.json`. Автоматическая установка системной службы не выполняется.

## Какие инструменты нужны

| Инструмент | Для чего | Без него |
| --- | --- | --- |
| Node.js 24.12+ в ветке 24.x и собственные пакеты studio | Сервер, интерфейс, хранение проектов | Студия не запускается; стартер сообщает причину |
| FFprobe | Проверка собственных картинок и аудио | Импорт новых медиа недоступен; готовые шаблоны, текст, слои и ключи доступны |
| FFmpeg с `libx264` и `aac` | Экспорт MP4 и сведение звука | Можно монтировать и переносить проекты в ZIP; экспорт MP4 недоступен |
| Google Chrome | Покадровый экспорт через собственный playwright-core | Студия работает в браузере; MP4 недоступен |
| Python 3.14 и своё подключение GLM | Необязательные ИИ-правки | Полностью доступны ручное редактирование, превью, MP4 и ZIP при остальных зависимостях |

Node: <https://nodejs.org/en/download>. FFmpeg: <https://ffmpeg.org/download.html>. Chrome: <https://www.google.com/chrome/>. Установщики перечисленных внешних программ в комплект Motivelium не включены; Node уже есть внутри Windows-поставки Motivelium. SETUP не устанавливает программы глобально, не требует администратора и не подключает платные модели.

Проверка без запуска браузера:

```text
node launch.mjs --check
node launch.mjs --check --json
node launch.mjs --no-open
```

Отсутствующий необязательный инструмент не считается поломкой ручного редактора. Проверка FFmpeg включает наличие кодировщиков, а экспорт дополнительно проверяет запуск Chrome и структуру готового MP4. Если меняете пути инструментов, перезапустите сервер: результаты их проверки кэшируются на время процесса.

## Пути к инструментам

В кандидате `20261028-external-alpha` откройте «Настройки → Компоненты → Проверить компоненты». В дополнительных полях можно сохранить абсолютные пути к Chrome, FFmpeg и FFprobe; пустые поля включают автоматический поиск. После сохранения перезапустите эту копию студии. Настройки не устанавливают программы и не меняют GLM-профиль.


FFmpeg и FFprobe ищутся в PATH или в `runtime/bin/ffmpeg.exe` и `runtime/bin/ffprobe.exe` внутри этой копии. Chrome ищется в стандартных каталогах Program Files/LocalAppData. Альтернатива — свой файл **.local/runtime.json**:

```json
{
  "tools": {
    "ffmpeg": "D:/VideoTools/ffmpeg.exe",
    "ffprobe": "D:/VideoTools/ffprobe.exe",
    "chrome": "C:/Program Files/Google/Chrome/Application/chrome.exe",
    "python": "C:/Python314/python.exe"
  }
}
```

Пути с разделителями разрешаются относительно папки программы; абсолютные пути остаются абсолютными. Переменные `MOTIVELIUM_FFMPEG`, `MOTIVELIUM_FFPROBE`, `MOTIVELIUM_CHROME`, `MOTIVELIUM_PYTHON_LAUNCHER` имеют приоритет. Файл с настройками одной машины в комплект для другого человека не включается.

## Необязательный GLM

По умолчанию встроенный GLM **не настроен**. Внешний MCP подключается независимо от него. Студия не ищет ключи или профили Hermes/DSH. Для собственного подключения добавьте в локальный JSON раздел `glm`:

```json
{
  "glm": {
    "keyFile": "D:/Private/glm.key",
    "model": "glm-5.3",
    "visionModel": "glm-5.3-flash",
    "effort": "high",
    "proxy": ""
  }
}
```

Нужны собственная подписка и Python 3.14. Без указанного прокси запрос идёт напрямую; системный прокси не подставляется молча. При необходимости задайте свой `proxy`. Ключ хранится отдельным файлом и не отправляется браузеру. Переменные `MOTIVELIUM_GLM_KEY_FILE`, `MOTIVELIUM_GLM_MODEL`, `MOTIVELIUM_GLM_VISION_MODEL`, `MOTIVELIUM_GLM_PROXY` перекрывают локальные значения. Проверка состояния не вызывает модель; оплачиваемый запасной провайдер не используется.

## Папки данных и перенос

Установленный EXE обычно использует `%LOCALAPPDATA%/Motivelium`, исходники — `.local` рядом с кодом. «Настройки → Хранилище» показывает активный путь. На одном компьютере можно выбрать другую папку данных, посмотреть список и перенести выбранный проект копией через проверку состояния и SHA256 ресурсов. Источник не изменяется, история отмен остаётся у него. Другая машина — через ZIP. Не запускайте два сервера на одних данных.

## Ошибки старта

- **Нет Node/npm или неверная ветка:** установите указанный runtime, откройте папку заново и повторите SETUP.
- **Нет пакета / интерфейса:** запустите SETUP. Не копируйте node_modules с другой машины вместо установки по lockfile.
- **Порт занят:** выберите другой порт. Соседние серверы стартер не завершает.
- **API студии не загрузился:** старт завершается ошибкой; полный журнал — `.local/server.log`. Ранний проигрыватель не выдаётся за исправную студию.
- **Не читается runtime.json:** исправьте синтаксис либо временно переименуйте файл. Личные проекты не удаляйте.
- **Нет FFmpeg/FFprobe/Chrome:** настройте пути, проверьте `--check`, перезапустите сервер и повторите операцию.

Границы проверки конкретного Windows-комплекта указываются в протоколе поставки. Прежние локальные и Windows-прогоны не подменяют внешний пользовательский пилот.
