# Motivelium — известные ограничения

Сверка31.10.2026. Область публичной beta.1 — [RELEASE_BETA1.md](RELEASE_BETA1.md); отличия рабочей сборки и дальнейшие приращения — [CAPABILITIES.md](CAPABILITIES.md) и [DEVELOPMENT.md](DEVELOPMENT.md). Предыдущие Windows-прогоны подтверждают конкретные старые комплекты, не новые видеослои/ScreenGuide. Этим проходом состояние установленного ярлыка и все GPU не проверялись.

- **Клипы и звук.** В публичной beta.1 обычного видеослоя ещё нет. В рабочей сборке после неё реализован H264/AAC CFR-видеослой с trim/speed/hold/hide и ScreenGuide; ограничения — VIDEO_CLIPS.md и SCREEN_GUIDE.md. Захвата экрана/автоматической телеметрии пока нет. Общий микс поддерживает моно и стерео WAV/MP3; многоканальные файлы нужно сначала преобразовать. Очень длинный декодированный источник ограничен памятью предпросмотра.
- **Раскадровка и текст.** Сборка из карточек создаёт заготовку обычными узлами. Её нужно просмотреть и довести. Переносы и размер текста рассчитываются при сборке; последующее произвольное изменение текста может потребовать ручной правки. ZIP с раскадровкой использует формат2 и требует нового читателя.

- **Внешние программы.** .NET Framework 4.8 и WebView2 Evergreen Runtime нужны для запуска окна. FFprobe нужен для импорта своих изображений/аудио; Chrome, FFmpeg с libx264/AAC и FFprobe — для MP4. Автоматической установки этих компонентов нет. Без инструментов MP4 доступны редактор, встроенные шаблоны и ZIP.
- **Подпись.** Setup и EXE без сертификата доверенного издателя. Windows может показать неизвестного издателя. Установщик/удаление требуют UAC, редактор работает без повышения.
- **Проекты.** Удаление программы сохраняет `%LOCALAPPDATA%/Motivelium`. Перенос старой `.local` выполняется ZIP или отдельной копией через настройки хранилища; автоматической миграции нет. ZIP передаёт текущее состояние, но не старую историю отмен, ИИ-задания и готовые MP4.
- **Размер ZIP.** До 256 МиБ архива и суммарной распаковки, до 64 МиБ на ресурс и до 256 ресурсов. Самодостаточные модели не должны ссылаться на внешние файлы.
- **Экспорт.** Одно задание одновременно; до 5 минут, 36 000 кадров, 120 fps, 4096 по стороне, 8,8 Мп и 64 аудиодорожек. Нечётные размеры дополняются до чётных. Незавершённый экспорт после перезапуска помечается ошибкой; автоматического повторного запуска нет.
- **Формат проекта.** Размер, fps и длительность выбираются при создании. Сложное изменение формата готового ролика пока не реализовано. Пользовательские шаблоны нельзя сохранять в общий встроенный каталог.
- **3D и эффекты.** Поддерживаются проверенные статические GLB/GLTF и подготовленные детали. Универсальная поддержка skins, morph targets и всех сжатых форматов не заявлена. Внешние многопроходные программы не импортируются произвольно.
- **Воспроизводимость GPU.** При холодных или разных GPU-контекстах наблюдались малые различия отдельных пикселей. Тайминги, граф и байты ресурсов сохраняются; побитная идентичность картинки разных GPU не обещается.
- **ИИ.** Внешнему MCP нужен собственный клиент с поддержкой локального MCP; модель и оплата находятся у этого клиента. Python и GLM-профиль ему не нужны. Необязательные встроенные правки одного объекта через GLM требуют своей подписки, ключа и Python 3.14. Ключи автора и профили Hermes/DSH не используются.
- **Диагностика запуска.** Инструментальная проба alpha.3 однажды получила отказ записи служебного файла до старта backend. При обычном запуске пользователя из «Пуска» ошибка не повторилась; точный механизм различия контекстов не установлен. Не нужно менять ACL или отключать защиту Windows по предположению. На новой Windows 11 VM обычный запуск, запись, перезапуск, MP4 и ZIP прошли; причина прежнего различия контекстов на машине разработчика остаётся неизвестной. При повторении сохраните точный текст и журнал, не удаляйте проекты.
