# Motivelium 0.1.0-alpha.3

Предварительная версия локальной студии программного видео для Windows x64.
Собственный код — MIT; условия библиотек, шейдеров и моделей — в `THIRD_PARTY.md` и `licenses/`.

## Что доступно

- Сцены и слои, движение и размер объектов на холсте, порядок слоёв, ключи анимации, отмена и повтор.
- Живые галереи эффектов, переходов между сценами, масок, шейдеров и редактируемых композиций. Примерка до применения.
- Статические GLB/GLTF, выбор деталей, сборка и разборка, камера, свет и атмосфера.
- Три стартовых шаблона с заменой текста, изображений и музыки; три компактных демопроекта.
- Необязательные ИИ-правки с кадрами до/после и ограниченным числом попыток. Применение подтверждает пользователь.
- MP4 H.264/AAC и ZIP проекта с ресурсами для переноса в другую копию студии.
- Windows EXE, установщик с UAC и ярлыком «Пуска». Редактор работает без повышения. Данные отделены от программы и сохраняются при удалении.

## Проверки

21.10.2026 полный маршрут пройден на новой Windows 11 LTSC x64, build 26100, в Hyper-V, без профиля разработчика и сети. Проверены настоящий Setup `/S` без тестового `/QA`, регистрация Windows, ярлык и контрольные суммы 2956 файлов. Редактор и сервер работали обычными токенами.

Создан проект из «Спектра», заменены текст/PNG/MP3, сохранён и открыт после перезапуска. MP4: 12 секунд, 1280×720, 30 fps, 360 кадров H.264 и AAC. Независимо проверены звук с заданными громкостью/смещением, ZIP и четыре ресурса, равенство полного графа после импорта и отмены правки.

Последний полный прогон автоматических тестов: 310/310; TypeScript без ошибок. Исходники отдельно распаковывались и собирались в установщик без лабораторных данных автора.

Это одна новая VM и один полный тестовый ролик. Ручной мастер, системные диалоги сохранения, SmartScreen и все сочетания GPU/Windows этим испытанием не покрыты. Первый служебный GET сбросил соединение; в повторном полном прогоне ошибка не повторилась, причина не установлена. Самостоятельные пробы новых пользователей ещё нужны.

## Установка и ограничения

Нужны Windows 10/11 x64, .NET Framework 4.8 и WebView2 Evergreen. Node.js включён в установщик. Для импорта своих медиа нужен FFprobe; для MP4 — Chrome, FFmpeg с libx264/AAC и FFprobe. Внешние программы устанавливаются отдельно. Для необязательного GLM нужны собственный ключ и Python 3.14.

Setup и EXE пока без подписи доверенного издателя. Полный список ограничений — [KNOWN_ISSUES.md](KNOWN_ISSUES.md), настройка — [INSTALLATION.md](INSTALLATION.md).
