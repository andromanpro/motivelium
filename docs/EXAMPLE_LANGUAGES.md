## Пользовательский маршрут

**Примеры → Язык примеров → English**; в английском UI **Examples → Example language → English**. В шаблонах свой selector **Template language**. Начальный выбор берётся из UI, затем выбирается независимо. Карточка показывает фактический язык контента.

Preview не записывает проект в библиотеку. Create your copy / Create project создаёт отдельный редактируемый документ. Смена UI или каталога не переводит уже созданный проект. Ручные правки, Apply/Undo/Redo, MP4 со звуком и ZIP работают обычно. Исходные имена деталей импортированных моделей сохранены.

## Контракт

- Язык — стабильное значение ru | en. Не использовать переводимые подписи как ID.
- GET /api/v1/examples?language=en и /api/v1/templates?language=en возвращают английские варианты; без параметра сохраняется RU; неизвестный язык — HTTP400.
- Явные presets: letters-en-v1, discharge-film-en-v1, matter-film-en-v1, collage-paper-en-v1. Старые presets остаются русскими.
- Виртуальные templateId: spectrum-en, route-en, signal-en; version1. project.en.json/manifest.en.json лежат рядом с RU; ресурсы читаются из общего каталога.
- MCP catalog {kind: "templates", language: "en"} и create_project с templateId используют те же версии. Имена MCP-инструментов стабильны.
- Карты copy привязаны к ID конкретного рецепта и применяются при создании встроенного контента. Произвольные пользовательские Project не подвергаются поиску/замене.
- Коллаж заново создаёт 11 глифов / 44 маски для MAKE IT / YOURS; пробел не становится осколком. Геометрия таймлайна, камера, эффекты и музыка общие.
- ZIP хранит контент, а не пользовательскую настройку UI. PNG/GLB/музыка общие для RU/EN по SHA.

## Проверки

400 тестов и TypeScript в каноническом снимке; Chrome UI: превью и копия всех семи вариантов, редактирование/Undo шаблонов и семь ZIP-импортов. Новые английские MP4 технически проверены, финальные контакт-листы просмотрены. Подписочный GLM Flash реально прочитал шесть листов; замечания к микротексту сверены с исходным размером. Модельный вердикт не заменяет приёмку автора.

Firefox MCP прошёл изолированный пользовательский маршрут с английским профилем. Windows EXE сохранил язык/тему и полный проект после перезапуска; нативный save-export сохранил MP4 и ZIP, импорт совпал по графу и всем ресурсам. MCP из Windows payload: каталог EN, примерка/3PNG/Apply/Undo, остановка по общему бюджету. Подробные квитанции находятся в поставке кандидата.
