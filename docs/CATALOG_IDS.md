# Постоянные ID категорий

Сборка `20261029-en02` отделяет значения фильтров и категорий от видимых надписей. Ранее, например, строка `Частицы` одновременно задавала категорию и показывалась пользователю. Это связывало логику с одним языком.

| ID категории / фильтра | Русская подпись | English |
|---|---|---|
| `all` | Все | All |
| `entrance` | Появление | Entrance |
| `motion` | Движение | Motion |
| `distortion` | Деформация | Distortion |
| `light-color` | Свет и цвет | Light and colour |
| `particles` | Частицы | Particles |
| `exit` | Уход | Exit |

Для звуков используются `clicks`, `interface`, `motion`, `impacts`; `all` является общим фильтром. В шейдерной библиотеке общий фильтр источника тоже использует `all`; имена семейств источников остаются собственными именами пакетов.

Определения и нормализация находятся в `studio/domain/catalogIds.ts`. Новый интерфейс хранит ID в состоянии и `value` элементов. Подпись выбирается отдельно. Старые русские входные значения принимаются нормализатором для совместимости; неизвестная категория не превращается в «Все» и возвращает пустую выборку/ошибку в зависимости от контекста.

`CATALOG.category` и `SoundEntry.category` возвращают постоянный ID. Для описания доступна отдельная `categoryLabel`; MCP-поиск сохраняет русские ключевые слова и прежние подписи. ID самих эффектов, параметры, сохранённые проекты и ресурсы не переименовываются. Изменение языка не является транзакцией проекта.

Представление эффектов в `catalogView.ts` переводит имя, описание, подписи вариантов и подсказки, сохраняя evaluator, значения по умолчанию и `choices.value`. Этот слой используется только интерфейсом; renderer и wire-формат остаются общими. `uiLabel` не применяется ко всему содержимому проекта.

Проверки: уникальность и допустимость ID, все прежние русские aliases, равенство выборок, неизвестное значение, неизменность исходных определений/параметров и реальное переключение языка с выбранной категорией `particles` и теми же двумя карточками. Для звуков проверена категория `clicks` с тремя карточками, примеркой, применением и Undo.
