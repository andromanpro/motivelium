# Работа ИИ с Motivelium

Сверка31.10.2026. Цель: агент собирает редактируемый ролик, человек рассматривает результат и доводит его в студии.

Перед новой возможностью прочитать [карту](CAPABILITIES.md), найти текущий ID и новое приращение в [ветках](DEVELOPMENT.md). Проверить `node tools/capability-map.mjs --check`. Наличие HTML-фильма, внешнего скрипта, нативного механизма и функции в опубликованном EXE — разные состояния.

Для создания видео: краткий замысел → карточки/ключевые кадры → короткая проба → каталог/обычные операции → реальная примерка → ограниченная доработка → явное применение → ручная шлифовка → MP4/ZIP. Всё использует одну историю и renderer. [MCP](MCP.md) предоставляет компактные выборки, рецепты времени и общий бюджет; он не вызывает модель вместо внешнего клиента.

Встроенный GLM проверяет выбранный объект, NEXT-03 предлагает проверку всего фильма. Готовая раскадровка и сборка из неё существуют; NEXT-04 расширяет варианты/пометки. Готовое оформление скринкаста существует; NEXT-02 добавляет захват с телеметрией. Разрешение на план не означает разрешение запустить все ветки или платные запросы.

После изменения обновлять JSON-карту: реализацию, ручной/MCP доступ, ограничения и включение в выпуск раздельно. `--check`, затем `--build` обновляют представления. Историческая alpha.3 и старые этапы сохранены [отдельно](history/AGENT_WORKFLOW_through-2026-10-31.md).
