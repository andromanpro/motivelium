# Готовность первой беты Motivelium

Обновлено30.10.2026. Следующий номер предлагается **0.2.0-beta.1**. Это предложение, а не опубликованный выпуск. Текущие `version.json` и готовые установщики сохраняют `0.1.0-alpha.4 / 20261029-alpha4-rc-en`; GitHub alpha.3 не заменялась.

## Что означает бета

Основной сценарий: человек ставит студию, подключает своего ИИ по MCP, получает редактируемую примерку с настоящими кадрами, доводит её вручную и сохраняет MP4 со звуком и переносимый ZIP. Бета проверяет этот сценарий на компьютерах других людей. Номер0.1 не измеряет количество функций; он остался от первых выпусков.

## Уже подтверждено

- Четыре встроенных демо, три шаблона, RU/EN интерфейса и встроенного содержимого, светлая/тёмная/системная тема. Авторский текст проектов автоматически не переводится.
- Кандидат29.10: 400 тестов, TypeScript/production, браузерный путь создания/MP4/ZIP, Firefox/MCP, собственный WebView2. Это свидетельства конкретных прогонов, не обещание всех GPU.
- Прежняя Win11LTSC26100 в Hyper-V повторно использована для текущего Setup: настоящий `/S` без `/QA`, регистрация/цель ярлыка Пуска,4151SHA, обычные права редактора/сервера/UI-worker. Текст/PNG/MP3 → перезапуск с тем же графом →12с720p MP4/H264/AAC → ZIP в другое хранилище/4SHA → правка/Undo. Удаление/повторная установка сохранили379 файлов данных. Новых VM, VHD, ISO и клонов не создавали; VM после проверки выключена.
- Новый реальный подписочный GLM Flash работал только через MCP, без исходников и shell: каталог,12с проект,3PNG примерки, применение/Undo/Redo, MP4 и ZIP. Полный цикл занял около351с. Проверка модели не равна художественной приёмке: она пропустила наложение текста на фото; в отдельной копии оно исправлено через студию с Apply/Undo/Redo. Исходник GLM сохранён.
- Убрана привязка чтения ZIP к одному каналу `alpha`: одинаковые правила alpha/beta/rc/stable и корректный порядок стабильного выпуска после prerelease. Сборщик берёт версию из `version.json`, а NSIS — из аргументов сборки. Исторические ссылки и зависимости не переименовываются.

## Конечный остаток перед маркировкой и публикацией беты

1. Выбрать номер выпуска; синхронизировать его и собрать **новый канонический** комплект. Проверенный alpha.4 нельзя просто переименовать в beta. Версию минимального reader в ZIP формирует фактическая сборка.
2. На **этой же** VM установить именно конечный beta Setup и коротко повторить импорт старого ZIP, подключение MCP из включённого Node, применение/отмену и MP4. Полный старый прогон повторять без новых причин не нужно. Довести EN-настройки: прежний дополнительный тест искал «Настройки» вместо «Настройки студии» внутри редактора и остановился. Это ошибка селектора, а не доказанный дефект программы; успешный EN-tail на Win11 не заявляется. Не создавать новую ОС ради этого шага.
3. Верифицировать итоговые SHA, документацию, комплект примеров и Release notes; получить решение автора о публичном Pre-release. Проверка регистрации ярлыка в VM не выдается за наблюдавшееся ручное нажатие в «Пуске». Native Save As в opt-in QA обходился тестовым путём и требует отдельной ручной проверки, если меняется этот механизм.

## Что допустимо оставить после первой беты

Импорт произвольных видеоклипов, новые эффекты, автоматическая установка FFmpeg/Chrome, сертификат подписи и обновления приложения. Эти задачи не нужны для объявления беты программного создания видео при явно описанной области применения. Chrome/FFmpeg/FFprobe/WebView2 должны быть установлены пользователем; диагностика и пути доступны в студии. Внешний ИИ оплачивается выбранным пользователем клиентом. Windows10/11 x64 — целевая настольная платформа; экспорт не проверен на всех GPU и WebView2.
