# Готовность выпусков Motivelium

Сверка 31.10.2026. Выпуск0.2.0-beta.1 сборки20261030-beta1 уже подготовлен и опубликован по прежнему поручению; он не находится на стадии «выбрать номер и опубликовать первую бету». Состав — [RELEASE_BETA1.md](RELEASE_BETA1.md). Архив исходников и его SHA зафиксированы в [capabilities.json](capabilities.json).

После выпуска появились только рабочие MEDIA-02/03: нативные видео и оформление скринкаста. Они ещё не входят в опубликованный установщик. На последнем этапе425тестов/tsc, настоящий MCP/UI, browser/onboarding, MP4/ZIP и RU/EN/темы прошли; художественная оценка короткой пробы и новый Windows-прогон не заявляются. Не выдавать предыдущий Windows-тест за проверку нового видеодекодера.

Следующий кандидат — NEXT-01 [плана развития](DEVELOPMENT.md): точный новый комплект → прежняя VM без создания новой ОС → видео/точки/Undo/MP4/ZIP/restart и сохранность старых проектов → SHA/документация → отдельное решение о публикации. На старте проверить реальную версию и папку данных ярлыка, а не вывести их из исходников.

Прежние beta-чеклисты, проверки и состояние статей/урока были историческими срезами. Они сохранены [здесь](history/BETA_READINESS_through-2026-10-31.md); старые формулировки «не опубликовано» не являются текущим статусом. Публикации этим проходом не выполняются.
